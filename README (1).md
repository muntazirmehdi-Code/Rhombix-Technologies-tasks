# Online Quiz Game - C++

**Rhombix Technologies Internship | Month 2 | Task 1**

## Description
A feature-rich console-based Online Quiz Game built in C++. Players can register, take quizzes on various topics, view their results with grades, and compete on the leaderboard.

## Features
- **User Registration** – Enter your name before starting
- **15 Questions** across 5 topics: Science, History, Technology, Geography, Mathematics
- **Randomized Questions** – Different order every time
- **3 Quiz Modes** – 5, 10, or 15 questions
- **Scoring System** – Score, percentage, and grade (A+ to F)
- **Answer Review** – See correct answers after quiz
- **Leaderboard** – Rankings by score and time
- **Time Tracking** – Tracks how long you take

## How to Compile & Run

### On Linux / Mac:
```bash
g++ -o quiz_game quiz_game.cpp
./quiz_game
```

### On Windows (MinGW):
```bash
g++ -o quiz_game.exe quiz_game.cpp
quiz_game.exe
```

### On Windows (Visual Studio):
Open `quiz_game.cpp` in VS and press **Ctrl+F5** to run.

## How to Play
1. Run the program
2. Select **Start New Quiz** from the menu
3. Enter your name
4. Choose number of questions (5 / 10 / 15)
5. Answer each question by typing **1, 2, 3, or 4**
6. View your results and answer review
7. Check the leaderboard!
